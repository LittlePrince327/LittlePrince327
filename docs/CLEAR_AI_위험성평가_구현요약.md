# CLEAR AI 위험성평가 구현 요약

## 목적과 범위

안전공학 석사학위 논문 연구 과정에서 위험성평가 자료 작성과 검토를 지원하기 위해 구현한 AI 기반 웹 서비스입니다.

현장 사진과 작업 상황 설명을 입력받아 위험요인·현재조치·개선대책·위험수준의 **초안**을 생성하고, 사용자가 검토·수정·선택한 결과를 저장하는 흐름을 구성했습니다.

> AI가 최종 판단을 대신하지 않습니다. 제 담당 범위는 **AI 기능 · FastAPI 백엔드 · 데이터 저장 · AWS 실행/배포 환경** 중심이며, 논문 저자가 아니라 시스템 구현 기여자입니다.

## AI / Backend Flow

```text
현장 사진 + 작업 설명
        ↓
MIME · 이미지 수 · 용량 검증 / 이미지 압축
        ↓
OpenAI Responses API · Vision + Text
        ↓
JSON 추출 · 키 정규화 · Pydantic 검증
        ↓
위험요인 · 현재조치 · 개선대책 · 위험수준 초안
        ↓
사용자 검토 · 수정 · 선택
        ↓
PostgreSQL(RDS) 저장 · S3 private 이미지 연동
```

## 구현 확인 범위

- OpenAI Responses API 기반 이미지+텍스트 위험성평가 초안 생성
- 이미지 MIME·개수·용량 검증 및 압축
- 가변 이미지 입력 처리
- JSON 추출 · 영문/한글 키 정규화 · Pydantic 검증
- 대표 평가 API `/assess` 구성
- 사용자 선택 결과 저장 흐름 `/api/hazard-decisions` 구성
- PostgreSQL 기반 RDS 저장 구조 연동
- S3 private 이미지 연동
- EC2 환경에서 Nginx · Uvicorn · systemd 기반 실행 환경 구성
- GitHub Actions 기반 main 브랜치 자동 배포 흐름 구성

## 표현 경계

- 위험성평가 **최종 판단 자동화**가 아니라 **초안 생성 및 자료 작성 지원**입니다.
- 보고서 기능은 완전 자동보고서 제품으로 표현하지 않고, 평가 결과를 보고서 형식으로 연결하는 지원 흐름으로 설명합니다.
- 프론트엔드 화면 구현은 담당 범위에서 제외합니다.

## 후속 과제

- 전문가 검증 체계와 사용자 피드백 기반 품질 개선 루프
- 운영 로그·오류 모니터링 강화
- 회사별 보고서 템플릿 자동 적용
- 반복 평가 자동 보고서 생성
- 정기 점검 일정 및 개선조치 기한 알림
