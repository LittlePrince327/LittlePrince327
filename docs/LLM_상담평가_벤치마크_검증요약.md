# LLM 상담 요약·품질 평가 벤치마크 검증 요약

## 목적

전화 상담 분석과 상담 품질 평가 자동화 가능성을 검토하고, 상담 요약·평가에 적합한 오픈소스 LLM 상위 후보군을 도출하기 위한 비교 실험입니다.

## 수행 범위

- 상담 데이터 활용 아이디어 **7개** 기획
- GGUF 기반 오픈소스 LLM 후보 조사 및 로컬 실행
- 동일 상담 예시 **1건**과 동일한 **3단계 프롬프트** 적용
- 동일 모델 계열의 양자화 버전과 미완료 실행을 포함한 **26개 테스트 기록** 정리
- 완전한 3단계 출력과 8개 평가 결과가 확보된 **12개 모델** 상세 비교
- LLM 출력 자체를 **8개 항목 × 30점 = 240점**의 프로젝트 자체 기준으로 평가

> `26개`는 고유 베이스 모델 26종을 의미하지 않습니다. 동일 모델 계열의 양자화 버전과 후보·미완료 실행 기록이 별도 항목으로 포함된 테스트 기록 수입니다.

## 3단계 프롬프트

1. 상담 목적과 주요 내용을 JSON 형식으로 요약
2. 한 문장 제목 · 2문장 요약 · 핵심어 1개 생성
3. 통화 시작 인사, 상담원 이름 안내, 통화 종료 인사, 욕설 여부, 고객 발화 중단 여부를 판정하고 개선점 생성

3단계 상담원 평가는 기준 충족 항목마다 1점씩 합산해 5점 만점으로 산출합니다.

## LLM 출력 평가 기준

아래 8개 항목은 상담원 5점 평가와 별개로, LLM 출력의 형식 준수와 품질을 비교하기 위한 자체 평가 기준입니다.

- 정확한 답변 형식
- 점수 합산 정확성
- 인사·마무리 인사 판정 정확성
- 욕설 여부 판정 정확성
- 출력 일관성
- 요약 품질
- 핵심 단어 추출 적절성
- 개선점의 타당성

각 항목 30점, 총 240점입니다.

## 상위 후보군

| 모델 | 크기 | 점수 |
|---|---:|---:|
| Microsoft Phi-4 Q4 | 14B | **230/240** |
| Llama-3 Korean Bllossom Q4_K_M | 8B | **230/240** |
| Mistral-Small 24B Instruct Q4_K_L | 24B | **230/240** |

## 해석 경계

- 공인 벤치마크가 아닌 **프로젝트 자체 평가 기준**입니다.
- 제한된 상담 예시 **1건**을 이용한 후보 비교입니다.
- 공동 최고 3개는 단일 운영 모델 확정이 아니라 **상위 후보군 도출 결과**입니다.
- AI 활용 아이디어 7개는 구현 완료 기능이 아니라 **기획 결과**입니다.
- STT 전사와 텍스트 요약 코드는 각각 존재하지만, 상위 LLM 후보와 하나의 배치 또는 API 서비스로 연결한 운영 파이프라인은 구현하지 않았습니다.

## 후속 과제

- 실제 상담 데이터 대상 요약·평가 정확도 측정
- 모델별 응답 시간·메모리 사용량·처리 실패 여부 측정
- 상담 음성 → STT → 요약 → 상담원 응대 평가 → 결과 저장 흐름 통합
- 상담 관리자 검수 절차 마련 후 운영 적합 모델 선정
